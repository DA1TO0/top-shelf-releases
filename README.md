# TopShelf — выпуски

Отсюда программа TopShelf получает обновления. Здесь только готовые установщики, исходного кода нет.

Скачать: откройте последний выпуск в разделе **Releases** справа и возьмите `TopShelf-Setup-….exe`.
Каждый установщик подписан ключом разработчика (файл `.sig` рядом) — TopShelf ставит обновление,
только если подпись сходится.

# TopShelf — releases

TopShelf downloads its updates from here. Only ready-made installers, no source code.
Download `TopShelf-Setup-….exe` from the latest release under **Releases**.
